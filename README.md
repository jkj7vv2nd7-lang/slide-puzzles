# スライドパズル工房 ― 箱入り娘・15パズル・オシドリの遊び

古典的なスライドパズルを集めた単体のWebアプリです。ブラウザで開くだけで遊べます（インストール不要・通信不要）。

**公開ページ：** https://jkj7vv2nd7-lang.github.io/slide-puzzles/

## 収録パズル

- **15パズル** ― 1〜15のタイルを順に並べる。転倒数の偶奇を判定し、解ける配置だけを出題します
- **箱入り娘** ― 大きな駒「娘」を出口まで運ぶ古典パズル。最短81手は全探索で照合済み。ヒント機能つき
- **ダッド・パズル** ― 大きな駒を左上の角Aから右下の角Cへ。最短29手（本では59手の解を紹介）
- **オシドリの遊び** ― 一列の黒白の石をペアで移して色ごとにまとめる。3〜8組＋変形ルール2種（3個ずつ／白黒入れかえ）
- **ペーパークラフトキット** ― 3つのパズルの盤・駒と挑戦記録シートをA4印刷できます（アプリ内でPDF生成）

最短手数はいずれもプログラムで全探索して確かめた値です。

## 出典

高木茂男・中村義作『数理パズル』（中公新書）p77–91 の配置とルールをもとに制作しました。文章とプログラムは本アプリの書き下ろしです。

## 使い方

`index.html` をブラウザで開くだけで動作します。遊んだ記録（ベスト手数・時間）は端末の中にだけ保存されます。
